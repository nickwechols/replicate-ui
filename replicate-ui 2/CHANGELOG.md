# Changelog

## 1.0.0 (2026-10-22)

- Whole-site crawler: sitemap and nav discovery, template grouping, desktop and phone passes, real hover diffs, touch taps, scroll reveals, scrub and pin detection, stylesheet parsing, stack fingerprint, page-transition probe, contact sheets.
- Video poster frames via ffmpeg, because headless Chromium cannot play MP4.
- `--list`, `--only` and `--budget` for sandboxes that stop processes or cap command time.
- `compare-captures.cjs` scores a build against its reference capture.
- Skills: `replicate`, `capture`, `dna`, `compare`.
- claude.ai upload bundle built by `tools/build-claude-ai.sh`.
